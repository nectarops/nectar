# Governance

Dock-Weaver currently uses a maintainer-led model. Maintainers decide roadmap, releases, repository access, and whether changes meet the project's security and scope requirements. Decisions favor transparent discussion, technical evidence, backward compatibility, and the needs of self-hosting operators.

Routine changes require one maintainer approval and passing checks. Security-sensitive changes, breaking API changes, license changes, or governance changes require explicit approval from the repository owner. Maintainer status is earned through sustained, constructive contributions and may be removed for inactivity, security risk, or code-of-conduct violations.

As the contributor group grows, this document will be revised through a public proposal and review period.
