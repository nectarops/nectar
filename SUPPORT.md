# Support

Use GitHub Discussions for usage questions and GitHub Issues for reproducible bugs or focused feature proposals. Search existing reports first and include Nectar version, Docker version, host distribution, architecture, Swarm state, expected behavior, and redacted reproduction steps.

Never post passwords, private keys, Docker or registry tokens, initialization tokens, unredacted environment files, or private infrastructure addresses. Security problems belong in a private GitHub security advisory as described in [SECURITY.md](SECURITY.md).

The project is community-supported and provides no guaranteed response time or commercial SLA.
